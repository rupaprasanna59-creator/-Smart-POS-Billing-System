# 🚀 Smart POS Multi-Quantity Billing Engine

A modular desktop application built with Python and the Tkinter GUI framework. This system functions as a digital restaurant catalog allowing users to build a real-time shopping cart ledger with automated subtotal calculations.

## ✨ Core Features
- **Multi-Quantity Cart System:** Dynamically handles individual line-item mutations and tracks item counters.
- **Asynchronous Grid Layout:** Built using organized side-by-side layout frames keeping the product catalog and billing ledger separate.
- **Exception-Handling Pipeline:** Wrapped in a crash-proof `try/except` management block to ensure unbroken execution if local image paths are missing.
- **Dynamic Ledger Panel:** Built using scalable state dictionaries to automatically clear, append, and display billing parameters.

## 🛠️ Tech Stack Used
- **Language:** Python 3.x
- **GUI Framework:** Tkinter (Native Standard Library)
- **Data Architectures:** Python State Management Dictionaries & Lists

## 💻 How to Run Natively
1. Clone this repository or download the code file.
2. Ensure you have Python installed on your local computer machine.
3. Open your terminal or IDLE shell and execute the script:
   ```bash
   python app.py
   ```
